## 📌 About The Project

Netflix UI Clone is a frontend project inspired by the official Netflix landing page.

The project recreates the look and layout of a streaming platform homepage, including a navigation bar, hero section, promotional content, FAQ section, and footer.

I built this project using **HTML5 and CSS3** to improve my frontend development skills and practice creating modern, responsive website layouts.

## ✨ Features

- 🎬 **Netflix-Inspired Design:** A landing page inspired by Netflix's visual style.
- 🧭 **Navigation Bar:** Includes a Netflix logo, language button, and sign-in button.
- 🎥 **Hero Section:** Features a large background image, promotional heading, and email input.
- 📺 **Enjoy on Your TV:** A feature section with TV imagery and video.
- 📥 **Download Shows:** A section highlighting offline downloads.
- 📱 **Watch Everywhere:** Showcases streaming across different devices.
- 👨‍👩‍👧 **Kids Profiles:** A dedicated section for kids' profiles.
- ❓ **FAQ Section:** Displays frequently asked questions.
- 🔗 **Footer Links:** Includes multiple columns of footer navigation links.
- 📱 **Responsive Layout:** Uses CSS media queries to adjust the design for smaller screens.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/uroojrizwan-sketch/Netflix_UI-Clone.git
```

### 2. Open the Project Folder

```bash
cd Netflix_UI-Clone
```

### 3. Open the Application

Navigate to the `Netflix Clone` folder and open `index.html` in your browser.

No additional packages or installation are required.

**Note:** An internet connection is needed for externally hosted images, videos, and Google Fonts.
